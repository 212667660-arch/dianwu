# Agent 纯文本协议说明

协议用于约束模型 Agent 与后端之间的通信。协议必须是纯文本，使用固定中文字段名和 `【协议结束】` 结束标记。后端先解析、校验，再序列化为规范格式；不合格输出会进入一次修复流程。

## 诊断决策协议

协议头：`【协议:diagnosis-decision/v1】`

| 字段 | 含义 |
| --- | --- |
| 状态 | `CONTINUE` 或 `COMPLETE` |
| 当前轮次 | 当前诊断轮次，整数 |
| 已确认字段 | 已经确认的学习者信息 |
| 缺失字段 | 仍需追问的信息 |
| 置信度 | 0 到 1 之间的小数 |
| 下一问题 | CONTINUE 时必须给出问题 |
| 完成理由 | 当前决策理由 |

示例：

```text
【协议:diagnosis-decision/v1】
状态：CONTINUE
当前轮次：1
已确认字段：学科｜学习目标
缺失字段：薄弱知识点
置信度：0.55
下一问题：你最容易在哪一步出错？
完成理由：需要定位薄弱知识点
【协议结束】
```

## 学习者画像协议

协议头：`【协议:learner-profile/v1】`。固定字段：画像版本、年级、学科、当前水平、薄弱知识点、学习风格偏好、学习风格证据、认知层次、学习目标、推荐难度、置信度、待确认问题。

列表字段使用全角竖线 `｜` 分隔；未知值使用“未明确”，无待确认问题使用“无”。

```text
【协议:learner-profile/v1】
画像版本：1
年级：初二
学科：数学
当前水平：基础
薄弱知识点：一次函数图像｜待定系数法
学习风格偏好：视觉型
学习风格证据：偏好通过图像理解变化
认知层次：理解
学习目标：掌握一次函数基础题
推荐难度：基础｜提高
置信度：0.80
待确认问题：无
【协议结束】
```

## 学习资源协议

协议头：`【协议:learning-resource/v1】`。固定元数据字段：主题、画像版本、资源类型、目标难度。元数据后必须同时包含非空的 `【学习笔记】` 和至少一个 `【分层练习:难度】` 区块。每道练习题都必须同时包含题目、答案和解析。

```text
【协议:learning-resource/v1】
主题：一次函数
画像版本：1
资源类型：笔记｜练习
目标难度：基础｜提高
【学习笔记】
一次函数写作 y=kx+b。
【分层练习:基础】
题目1：求 y=2x+1 的截距。
答案1：1
解析1：令 x=0。
【协议结束】
```

## 错误与修复

- 缺少协议头：`PROTOCOL_HEADER_MISSING`。
- 缺少结束标记：`PROTOCOL_END_MISSING`。
- 字段缺失或重复：`FIELD_REQUIRED` 或 `FIELD_DUPLICATED`。
- 数字或枚举不合法：`FIELD_INVALID` 或 `FIELD_INVALID_NUMBER`。
- 学习笔记区块缺失或为空：`NOTE_SECTION_REQUIRED` 或 `NOTE_CONTENT_REQUIRED`。
- 资源练习区块缺失，或练习缺少答案、解析：`PRACTICE_SECTION_REQUIRED` 或 `QUESTION_TRIPLET_BROKEN`。

Agent 首次输出不合格时，后端把错误代码和原始输出放回修复提示；修复仍失败则将错误作为结构化异常返回，不把异常伪装成正常响应。
