# A3 学习软件竞品对比与后端优化方案

日期：2026-07-11

## 一、结论

当前 A3 后端已经具备“多轮诊断 -> 学习画像 -> 个性化资源 -> 流式输出 -> 会话持久化”的原型闭环，安全、模型网关、来源检索、缓存和测试基础也比较完整。

与成熟学习软件相比，最需要补齐的不是更多生成按钮，而是生成之后的学习闭环：

1. 把学习内容拆成可追踪的知识点和练习题。
2. 记录学生每次作答、错误类型和掌握度变化。
3. 根据掌握度安排下一次复习，并让下一次生成真正使用这些结果。
4. 对资源质量、题目难度和学习效果进行可观测评价。

## 二、竞品能力对照

以下是依据公开产品定位和常见使用流程提炼的能力对照，具体功能会因地区、套餐和版本变化。

| 产品或类别 | 用户能感知的核心能力 | 对 A3 后端的启发 |
| --- | --- | --- |
| Quizlet 类记忆学习产品 | 题卡、练习模式、错题反馈、阶段性掌握情况 | 资源不能只保存为一段文本，需要保存知识点、题目、答案、解析和掌握状态 |
| Khanmigo/Khan Academy 类 AI 导学 | 苏格拉底式追问、分步提示、避免直接代答、围绕学习目标辅导 | 增加提示层级和错误原因协议，让 Agent 根据学生当前尝试决定提示，而不是每次重新生成整份资料 |
| Duolingo 类技能树学习产品 | 技能图谱、短任务、即时反馈、连续练习、间隔复习 | 建立知识点状态和待复习队列；下一次任务应由掌握度、遗忘风险和近期错误共同决定 |
| Anki 类间隔重复产品 | 复习卡片、记忆结果、下一次复习时间、成熟的调度算法 | 后端应把复习调度作为独立领域服务，先支持可解释的基础调度，再保留替换 FSRS/SM-2 的接口 |
| 作业帮、猿辅导等题目型产品 | 题目解析、错题本、薄弱点归因、相似题和巩固练习 | 增加答题记录、错题归因和相似题请求；画像要能被真实学习行为持续修正 |

## 三、当前后端差距

### 已有能力

- 多轮诊断和画像版本化。
- 画像 Agent 与资源 Agent 分工。
- 学习笔记、分层练习和解析的协议校验。
- SSE 流式输出、取消生成、会话历史、资源缓存和来源快照。
- 模型网关切换、令牌保护、限流、基础评测和浏览器测试台。

### P0 缺口

| 缺口 | 当前影响 | 优先级 |
| --- | --- | --- |
| 没有知识点掌握度实体 | 画像中的“薄弱知识点”是静态文本，无法随答题更新 | P0 |
| 没有答题提交和自动评估接口 | 资源生成结束后，系统不知道学生是否真正学会 | P0 |
| 没有复习调度 | 无法形成“今天学、明天复习、错题再练”的连续路径 | P0 |
| 练习题没有独立 ID 和结构化记录 | 不能统计单题正确率，也不能精准生成相似题 | P0 |

### P1 缺口

- 缺少学习目标的时间范围、每日可用时间和期望完成日期。
- 缺少提示次数、答案揭示程度和学习过程指标。
- 缺少资源质量评分、题目难度校准和模型输出回归统计。
- 缺少按知识点查询学习进展的接口，前端只能读取整段会话。

## 四、推荐实施顺序

### S-009：学习闭环基础

1. 新增 `knowledge_points`、`question_items`、`answer_attempts`、`review_tasks` 等持久化实体。
2. 从 `learning-resource/v1` 中提取并保存练习题 ID、知识点、难度、答案和解析引用。
3. 增加答题提交接口，先支持规则判分和模型判分降级。
4. 根据连续答对、答错、提示次数和置信度更新掌握度。
5. 用可解释的间隔复习规则生成下一次复习时间。

### S-010：自适应资源生成

1. 资源 Agent 接收知识点掌握度和近期错误摘要。
2. 生成资源时明确本次目标知识点、题目难度和复习原因。
3. 对练习题进行数量、难度、答案一致性和解析完整性校验。
4. 将资源生成结果与学习效果关联，支持离线评测和真实联调趋势。

### S-011：学习过程观测

- 增加知识点进展、待复习列表、错题列表和资源质量统计接口。
- 记录可脱敏的阶段耗时、失败原因和用户反馈。
- 提供可供 Electron 前端直接渲染的摘要响应，避免前端解析内部协议文本。

## 五、验收指标

- 一次资源生成至少产生一个可追踪知识点和一道有唯一 ID 的练习题。
- 提交答题后，能返回判分、错误类型、解析和下一步建议。
- 同一知识点答错后，会进入待复习队列；答对后，下一次复习时间会后移。
- 后续资源生成请求会携带近期薄弱知识点和错误摘要。
- 旧会话和旧资源可以正常读取，数据库迁移可重复执行。
- 离线测试覆盖状态迁移、重复提交、跨会话隔离、调度边界和协议兼容。

## 六、范围控制

本轮不直接接入摄像头、语音识别、社交排行榜或复杂推荐模型。它们会扩大桌面端权限、隐私和数据采集范围，不能替代学习闭环本身。
