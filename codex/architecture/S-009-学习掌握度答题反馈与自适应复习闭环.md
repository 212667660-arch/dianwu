# S-009 学习掌握度、答题反馈与自适应复习闭环

日期：2026-07-11

## 设计目标

把 A3 从“生成一次学习资料”扩展为“生成、作答、反馈、复习、再生成”的持续学习闭环，同时保持旧画像协议、资源协议和历史数据可读。

## 核心边界

- 大模型负责生成画像、笔记、题目和解析，不直接修改掌握度或复习时间。
- 后端从已校验的 `learning-resource/v1` 中提取题目，建立稳定的数据库 ID。
- 答题判分和掌握度更新采用可解释、可测试的确定性规则。
- 学习状态版本参与资源缓存键；每次有效答题后版本递增，避免复用答题前的旧资源。
- 后续资源生成只接收最多八个低掌握度知识点摘要，控制上下文长度。

## 数据模型

| 实体 | 用途 |
| --- | --- |
| `knowledge_points` | 保存会话内知识点、掌握度、答题次数、连续答对和下次复习时间 |
| `question_items` | 保存资源中的题目、答案、解析、难度和所属知识点 |
| `answer_attempts` | 保存每次答案、判分、提示次数、错误类型和答题后的掌握度 |
| `review_tasks` | 保存每个知识点当前待复习任务、原因和到期时间 |

## 掌握度规则

- 初始掌握度为 `0.25`。
- 答错后掌握度乘以 `0.75`，清空连续答对，并立即进入复习队列。
- 答对后按提示次数降低增益，掌握度逐步逼近 `1.0`。
- 连续答对对应复习间隔为 `1、3、7、14、30` 天。
- 标签分为 `WEAK、LEARNING、PROFICIENT、MASTERED`。

## 一致性与安全

- 答题接口同时校验题目 ID 和会话 ID，不能跨会话提交。
- 可选幂等键保证重试不会重复更新掌握度。
- 会话删除通过 ORM 关系级联清理资源、题目、答题和复习数据。
- 启动迁移会回填旧画像知识点和旧资源题目，重复运行不会重复建数据。

## 接口

- `POST /api/sessions/{session_id}/questions/{question_id}/attempts`
- `GET /api/sessions/{session_id}/progress`
- `GET /api/sessions/{session_id}/reviews`
- `GET /api/sessions/{session_id}/mistakes`

## 后续扩展

规则判分适合数值、术语和短答案。开放题可在保持相同接口的前提下增加模型评分协议，但模型评分只能给出建议分和证据，最终状态更新仍由后端规则控制。
