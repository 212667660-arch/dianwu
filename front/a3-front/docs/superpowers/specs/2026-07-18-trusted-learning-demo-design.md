# S-036 可信学习交互与比赛演示设计

## 目标

让教材总结和例题回答明确区分教材证据与模型补充，支持页码范围、证据不足重检和答案复核；同时提供无需大文件和网络的一键比赛演示。

## 可信学习协议

- 学习请求可携带 `document_id`、`page_start`、`page_end`、`retrieval_expansion` 和 `verify_answer`。
- 上下文构建器只检索所选页码范围；证据不足时返回结构化原因和“重新检索/扩大范围”建议，不伪造引用。
- 输出按“教材依据”“模型补充”“结论/步骤”“引用”分区；模型补充不能使用 `[资料N]` 标记。
- 数学例题由 Reviewer Agent 检查公式格式、条件、代入、运算和最终答案；失败时自动修复一次，仍失败则展示复核警告。

## 演示模式

- 内置小型、许可清晰的数学演示集合、会话、画像、掌握度、题目和预生成资源；演示数据与用户数据分目录。
- 一键演示按固定步骤运行：载入演示空间、展示教材检索、Agent 状态、可信回答、答题前后掌握度、五类资源。
- 在线模型可用时允许切换真实生成；断网或模型不可用时明确显示“离线演示数据”，不得伪装实时结果。
- Agent 工作台显示阶段、耗时、状态、降级原因和重试入口，不显示内部提示词或敏感配置。

## 验收

覆盖页码范围检索、教材/补充区分、证据不足操作、Reviewer 通过/修复/失败、离线演示导入幂等、Agent 状态和掌握度前后对比；桌面断网条件下可完整演示。

## 自审

演示模式不改变真实业务默认路径，不包含受版权保护教材全文，不把预生成内容标为实时模型输出。
