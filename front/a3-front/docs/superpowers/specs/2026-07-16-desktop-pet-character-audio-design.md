# 桌宠角色导入与独立声音设计

## 目标与范围

在桌宠 MVP 上增加可安全使用的角色包导入/恢复默认能力，并增加完全本地的动作音效和语音鼓励。音效与语音各自具有独立开关和音量，不与动画速度耦合。

本阶段不实现角色市场、网络 TTS、录音上传、音色克隆、自动下载语音模型或复杂角色包版本迁移。

## 方案选择

采用“主进程受控导入 + renderer 本地播放”方案：

- Electron 主进程弹出目录选择器，只接受包含 `pet.json` 与 `spritesheet.webp` 的普通目录。
- 主进程验证文件类型、大小、清单和 atlas 几何后，原子替换 `userData/pets/current`。
- 导入或恢复默认后，控制器重载角色并重建独立桌宠窗口。
- 动作音效由 Web Audio 振荡器合成，不增加第三方音频版权。
- 语音使用系统 `speechSynthesis`，不调用外部 API，不上传鼓励文本。

未采用 renderer 传路径方案，因为它会扩大文件系统权限；未采用预置 MP3/WAV 方案，因为会引入额外授权和包体；未采用云 TTS，因为稳定性、隐私和密钥边界不适合当前本地桌面 MVP。

## 设置模型

`pet-settings.json` 在现有字段上增加：

```ts
interface PetSettings {
  visible: boolean
  scale: 0.5 | 0.75 | 1 | 1.25 | 1.5
  speed: 0.5 | 0.75 | 1 | 1.25 | 1.5 | 2
  soundEnabled: boolean
  soundVolume: number // 0、0.25、0.5、0.75、1
  voiceEnabled: boolean
  voiceVolume: number // 0、0.25、0.5、0.75、1
}
```

默认动作音效开启、音量 50%；默认语音关闭、音量 75%，避免应用升级后突然说话。旧设置文件自动补齐默认值。

## 声音行为

- 点击挥手：短促的双音提示。
- 双击跳跃：轻快上行三音。
- `review`：低音量检查提示音，同一状态重复广播不重复播放。
- `waiting`：播放完成提示音；语音开启时，从本地固定鼓励语中确定性轮换。
- `failed`：播放柔和失败提示；语音使用非责备式鼓励。
- `running`、左右拖动和 `idle` 不播语音，避免高频打扰。
- 语音全局最短间隔 30 秒；failed 可打断正在播放的普通鼓励，但不会叠加。
- 桌宠隐藏时停止合成器并取消语音；设置关闭时立即停止对应通道。

系统没有可用语音或 `speechSynthesis` 失败时静默降级为仅音效，不影响桌宠动画和主学习流程。

## 角色导入边界

导入目录必须满足：

- `pet.json` 为普通文件，不超过 64 KiB。
- `spritesheet.webp` 为普通文件，不超过 12 MiB。
- 目录不接受符号链接、额外路径或清单中的绝对/穿越路径。
- 清单与 atlas 继续使用固定 192×208、8×9、1536×1872 契约。
- WebP 必须有 alpha，未使用格完全透明，透明像素不得残留非零 RGB。

导入先复制到 `userData/pets/.staging-*`，全部校验完成后替换 `pets/current`；失败时保留原角色。恢复默认只删除受控的 `pets/current`，不访问其他目录。

## IPC 与权限

主 renderer 新增固定方法：

- `petChooseCharacter()`
- `petResetCharacter()`

renderer 不提交路径。主进程验证请求来源后调用系统目录选择器。返回值只包含脱敏角色摘要、设置和状态。

桌宠 preload 不增加文件权限，只继续接收设置和状态；声音在独立桌宠 renderer 内执行。

## UI

书桌卡增加：

- 当前角色名称与“导入角色包”“恢复墨团”按钮。
- 动作音效开关与独立音量选择。
- 语音鼓励开关与独立音量选择。
- 本地语音隐私提示和导入错误提示。

Web 模式按钮和声音控件禁用，并显示“仅桌面应用可用”。

## 验证

- Node 测试覆盖设置兼容、声音值白名单、导入原子性、非法包不覆盖、恢复默认、热重载。
- renderer 纯逻辑测试覆盖音效计划、语音触发、冷却、隐藏/关闭取消。
- Vitest 覆盖固定 bridge、Web 降级和设置卡交互。
- 完整 `npm test`、`build:desktop`、`desktop:pack`。
- unpacked 验证导入测试角色、恢复墨团、两个音量独立保存、隐藏时停止声音；不宣称完成主观音色 QA。

## 后续保留

角色库、多角色长期保存、声音文件包、用户自定义台词、音色选择、无障碍字幕和全面音频/许可证 QA 留在后续阶段。
