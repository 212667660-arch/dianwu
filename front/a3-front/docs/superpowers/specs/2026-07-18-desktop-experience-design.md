# S-035 桌面诊断、首次启动与墨团体验设计

## 目标

让全新安装用户能完成首次启动配置；后端失败时能一键诊断和导出脱敏日志；托盘、版本、更新入口和墨团设置满足长期桌面运行需要。

## 架构

- Electron 主进程保存版本化 `desktop-state.json`，仅记录向导完成、AI 暂停、窗口和墨团偏好。
- 首次启动向导检查后端、数据目录、模型配置和 OCR 能力，允许跳过在线模型并进入离线演示。
- 托盘菜单固定提供“显示主窗口、显示墨团、暂停/继续 AI、完全退出”，状态实时同步。
- `desktop-diagnostics.mjs` 汇总应用版本、平台、路径可写性、后端状态、OCR 能力和最近脱敏日志；导出 ZIP/JSON 到用户选择位置。
- 版本页展示应用、后端协议和 OCR 引擎版本；自动更新采用显式检查入口，未配置发布源时返回可解释的“当前为离线构建”。
- 墨团增加角色预览/恢复、音效与语音音量、静音、始终置顶、多屏边界钳制和降低空闲帧率；学习状态继续映射动作。

## 安全

诊断和日志必须移除 API Key、桌面令牌、Authorization、用户原文、原始本地路径和模型请求体；renderer 只能请求生成诊断或打开导出对话框，不能读取任意日志路径。

## 验收

Node 测试覆盖状态迁移、托盘动作、暂停 AI、诊断脱敏、版本与更新状态、多屏边界、置顶和低功耗；Vue 测试覆盖首次启动与设置页；桌面冒烟覆盖隐藏/恢复、托盘退出和零残留进程。

## 自审

自动更新只实现安全检查与状态展示，不在没有正式发布签名和更新源时静默下载或安装。
