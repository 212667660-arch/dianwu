# 内置三语简化版设计

## 目标

默认使用简体中文，同时把 `en-US` 与 `zh-TW` 作为应用内置语言提供即时切换。当前阶段不实现网络下载、签名、安装、版本升级或语言包仓库。

## 架构

- `zh-CN` 继续作为完整基准目录与 fallback locale。
- `en-US`、`zh-TW` 使用内置覆盖字典；运行时将中文基准与覆盖字典合并，因此缺失翻译稳定回退中文。
- 启动时注册三种语言并从 `localStorage` 恢复合法 locale；非法或损坏值回退 `zh-CN`。
- 桌面设置页把三种语言都显示为内置语言，点击“使用此语言”立即激活并持久化。
- 保留现有 download/import/remove 事件与正式 controller 边界，但简化模式不展示这些操作。

## 范围

首版覆盖品牌、主导航、语言设置卡和桌面设置主要文字，证明切换、持久化和 fallback 链路可用。其他尚未人工翻译的消息继续显示中文，不伪装成完整翻译。

## 验证

- 运行时测试覆盖三种内置 locale、非法持久值回退、激活持久化和缺失键中文 fallback。
- 设置页测试覆盖三种语言可见、点击切换和刷新后恢复。
- 完整 Node/Vitest、类型检查和桌面构建回归。
