# S-039 用户验收缺陷修复设计

## 背景

用户在最终桌面版中发现四项可见问题：练习题出现两个看似都要填写的输入框且提交按钮被挤压；知识库点击收藏星号时上方批量工具栏闪动；学习助手提示“尚未完成诊断”却没有解释诊断含义和操作方法；连续点击墨团时角色长期保持更大的视觉状态。

本轮只修复这些用户验收缺陷，不改变后端学习协议、知识库数据模型、墨团素材包格式或现有安装目录结构。

## 根因

### 练习答案区域

`Assessment.vue` 在同一个三列网格中同时渲染答案文本框、未标注的提示次数 `el-input-number` 和提交按钮。Element Plus 数字输入具有自身最小宽度，窄内容区内会挤压并覆盖提交按钮；用户也无法理解第二个控件不是答案框。

当前产品没有“请求提示”交互，允许用户手工填写提示次数既不自然，也会污染答题数据。因此本轮移除手工提示次数控件，提交时保持兼容并向后端发送 `hints_used=0`。

### 收藏闪烁

单个星号收藏复用了批量操作 `runBulk()`：先把该资料写入批量选择，再提交，随后清空选择并重新请求整页资料。批量工具栏因此依次经历“选中一项、清空、重新渲染”，产生明显闪烁。

单个收藏改为局部乐观更新：保持原选择不变，立即更新当前卡片星号，只提交该文档的收藏请求；失败时恢复旧值。只有处于“仅收藏”筛选且执行取消收藏时，成功后才从当前结果移除该卡片。批量收藏仍保留原刷新流程。

### 学习诊断说明

`SmartTutor.vue` 只保存错误文本，丢失流事件或 `DesktopApiError` 的错误码，因此 `RESOURCE_NOT_READY` 与普通模型错误共用“本次请求未完成 / 重新编辑”提示。

界面将同时保存安全错误码。`RESOURCE_NOT_READY` 和 `PROFILE_MISSING` 显示专用学习诊断卡，明确说明：学习诊断是画像 Agent 通过几轮对话了解学习目标、基础和薄弱点，不是桌面程序故障诊断。

- 会话处于 `NEW` 或 `DIAGNOSING` 时，按钮为“继续学习诊断”，将一条清晰的诊断请求放回编辑框。
- 会话已经处于 `PROFILED` 时，说明画像已完成，按钮为“重新尝试刚才请求”，恢复原请求。
- 其他错误继续使用现有通用错误卡。

### 墨团点击视觉放大

窗口持久化设置和控制器回归均证明墨团窗口保持 `192×208`、`scale=1`，Canvas 绘制目标也固定。素材分析显示 idle 非透明高度约 138–140 像素，而 jumping 帧可达到 170 像素。当前 `createInteractionController.play()` 每次点击都会清除并重新创建到期计时器；连续双击会无限延长 jumping 状态，使更高的跳跃姿态长期保留，用户感知为持续变大。

同一种交互状态在当前动画周期内改为幂等：已有 `waving` 或 `jumping` 尚未结束时，重复触发不会重置状态、帧或到期计时器。不同交互状态仍可正常切换，动画结束后恢复原任务状态。窗口、Canvas 和缩放设置不变。

## 组件与数据流

1. `Assessment.vue` 只保留答案输入与提交按钮，提交函数固定传递零提示次数。
2. `KnowledgeLibrary.vue` 增加单文档收藏待处理集合和局部更新函数；`DocumentGrid.vue` 接收待处理 ID 并暂时禁用对应星号，防止重复请求。
3. `SmartTutor.vue` 增加 `streamErrorCode`、诊断错误计算属性和诊断恢复动作；流式与非流式错误都保留稳定错误码。
4. `pet-renderer.js` 的交互控制器记录当前交互状态，同状态重复播放直接返回而不续期。

## 错误处理

- 单收藏请求失败时恢复原资料对象和原列表位置，并显示安全错误消息。
- 单收藏响应中该文档返回 `ok=false` 时同样视为失败。
- 切换会话、重新发送和恢复普通错误时同步清空旧错误码，避免错误卡类型串线。
- 墨团交互取消、隐藏和窗口销毁继续使用现有清理逻辑。

## 测试设计

- 新增 Assessment 组件测试：每道题只有一个可填写控件，提交按钮可见，提交调用中的提示次数为零。
- 新增 KnowledgeLibrary 测试：点击星号不会改变批量选择数量，不重新请求文档列表，成功更新星号；失败回滚。
- 扩展 SmartTutor 测试：`RESOURCE_NOT_READY` 显示诊断解释和正确动作，普通错误仍显示重新编辑。
- 扩展 pet renderer 测试：重复触发同一种交互不会创建新计时器或延长动画生命周期；不同状态仍能替换。
- 运行定向测试、完整 `npm test`、桌面构建和 unpacked 生命周期验收。

## 验收标准

- 练习题只有一个答案输入框，提交按钮无遮挡。
- 单击收藏星号时批量工具栏选择状态不变化，无整页闪烁。
- 用户能从错误卡理解学习诊断是什么，并能一键进入正确下一步。
- 连续单击或双击墨团不会无限延长挥手或跳跃造成持续放大观感，动画结束后自动恢复。
- 前端、Electron、后端既有回归和实际桌面启动均通过。
