# S-034 知识库批量管理与回收站设计

## 目标

补齐批量选择、批量移动、批量移入回收站、恢复、永久删除、多集合、标签、收藏、排序、筛选、导入进度和重复文件提示，同时保持本地文件安全与现有检索兼容。

## 数据模型

- `KnowledgeDocument` 增加 `deleted_at`、`favorite`；文档记录是唯一实体。
- 现有 `KnowledgeCollectionDocument` 继续作为多对多关系，同一文档允许加入多个集合。
- 新增 `KnowledgeTag` 与 `KnowledgeDocumentTag`，标签名大小写不敏感且本地唯一。
- 回收站默认保留 30 天；软删除时隐藏检索、解绑会话并取消活动任务，但保留对象、元数据与集合关系快照。
- 永久删除才移除索引、块、对象文件和关系；仅当没有其他活动文档引用同一 SHA-256 对象时删除对象。

## API 与交互

- 文档列表支持 collection、trash、favorite、tag、status、sort、direction、query 参数。
- 批量端点使用固定动作协议：`move_to_trash`、`restore`、`purge`、`add_to_collections`、`remove_from_collections`、`favorite`、`tag`。
- 所有批量操作返回逐项结果，单个失败不回滚无关成功项；权限和 ID 校验仍为全有或全无。
- 导入重复 SHA-256 时返回已有文档、所在集合和“加入当前集合/跳过”的可解释结果，不重复复制对象。
- 前端新增选择模式、批量工具条、回收站视图、标签/收藏过滤、排序菜单和失败详情；进度显示阶段、页数、ETA 与错误说明。

## 安全与一致性

- 批量 ID 上限 200，集合和标签上限受 schema 约束。
- 恢复时若原集合已删除，文档进入“全部资料”且提示用户重新归类。
- 活动导入任务在软删除前先请求取消并等待终态。
- 搜索与 AI 上下文只包含 `deleted_at IS NULL` 的文档。

## 验收

后端覆盖迁移、关系、多标签、软删除、恢复、永久删除、重复提示和搜索隔离；前端覆盖选择、批量动作、筛选排序和回收站；Electron IPC 覆盖新路由白名单与请求上限。

## 自审

回收站不新增云同步、共享或权限系统；多集合复用现有关系表，不复制文档和索引。
